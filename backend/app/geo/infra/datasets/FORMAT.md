# Формат датасета газеттира

Файл датасета — **наш собственный формат**, а не формат поставщика. Сырые данные любого
поставщика (GeoNames, OSM, Natural Earth, …) приводятся к нему отдельным **адаптером источника**
при подготовке новой версии датасета; результат заливается ассетом GitHub Release и прописывается
в `manifest.toml`. Загрузчик знает только этот формат —
смена или добавление поставщика не трогает ни загрузчик, ни базу, ни код выше.

```
сырые данные поставщика ──адаптер──▶ CSV этого формата (Release) ──загрузчик──▶ geo_places
```

## Файл

- CSV (RFC 4180), UTF-8, первая строка — заголовок, сжат gzip (`*.csv.gz`).
- Набор колонок — ровно как ниже; порядок не важен.
- Одна строка — одно место.

## Колонки

| Колонка | Обязательна | Значение |
|---|---|---|
| `external_id` | да | Ключ места у поставщика **с префиксом источника**: `GeoNames:524901`. Из него выводится наш `id` места (uuid5) — один и тот же `external_id` всегда даёт один и тот же `id`, поэтому менять его у существующего места нельзя |
| `kind` | да | Тип места: `city`, в будущем `lake`, `river`, `mountain`, … |
| `name_en` | да | Имя на английском — фолбэк отображения для любого языка |
| `name_ru` | нет | Имя на русском. Пусто — перевода нет |
| `country_code` | нет | ISO 3166-1 alpha-2 (`BY`). Пусто — у места нет страны (море, океан, Антарктида) |
| `latitude`, `longitude` | да | Точка места в градусах WGS 84 |
| `population` | нет | Население. Пусто — неприменимо (у озера) |

Имена — колонкой на язык, как и в `geo_places`. Новый язык = новая колонка здесь, в таблице и в
`Language` / `PlaceNames`.

## Загрузка

- Место загружается upsert'ом по `id`: повторная загрузка того же файла ничего не меняет, новая
  версия обновляет существующие места и добавляет новые. **Места не удаляются** — на их `id`
  ссылаются поездки.
- Что уже загружено, помнит таблица `geo_dataset_loads` (`name`, `version`, `sha256`) — загрузчик
  пропускает датасет, если эта версия уже в базе.

## Лицензия

Текущий датасет `geonames-cities` — данные [GeoNames](https://www.geonames.org) под
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), изменённые: только населённые пункты с
населением от 5000, только английские и русские имена.
