# Исходные данные фронтенда

Файлы здесь — **источники**, а не то, что попадает в бандл. Приложение импортирует производные
артефакты из `src/data/`, которые собираются скриптами из `scripts/` и коммитятся рядом.
Руками производный файл не правят: меняют источник и пересобирают. CI пересобирает каждый
артефакт и падает, если закоммиченный разошёлся с источником.

## `world-countries.geo.json` — границы стран

| | |
|---|---|
| Артефакт | `src/data/world-countries.topo.json` (TopoJSON, читает `WorldMap`) |
| Пересборка | `make generate-world` (`scripts/build-world-topology.ts`) |
| Формат | GeoJSON `FeatureCollection`, 180 фич, `Polygon` / `MultiPolygon`, WGS84 |
| Детализация | ~10.7k точек, медианный сегмент ~0.7°, уровень Natural Earth 1:110m |
| Источник | не установлен. Файл добавлен вместе с первым экраном карты (`e7af471`, июнь 2026) и с тех пор считается каноническим |

Контракт, на который опираются карты:

- **`id` — ISO 3166-1 alpha-2** (`RU`, `BY`): по нему красятся посещённые страны и резолвится имя
  через `Intl.DisplayNames` (см. `docs/architecture.md`). Исключения — территории без кода,
  у них `id` равен имени: `Northern Cyprus`, `Somaliland`.
- **`properties.name`** — английское имя; запасное, когда кода нет или браузер его не знает.
- **Антимеридиан**: Россия и Фиджи разбиты в данных на части по ±180°. Кольцо Антарктиды
  проходит вдоль нижнего края от −180° до 180° и замыкается скачком через всю карту — этот
  скачок `WorldMap` рвёт (`ANTIMERIDIAN_JUMP`), иначе через карту тянулась бы полоса.

Детализацию не упрощать: она уже грубая, и на максимальном приближении (×8) любое упрощение
видно. Заменяя источник, сохраните контракт выше и обновите эту таблицу.
