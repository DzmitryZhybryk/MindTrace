# Changelog

<!-- markdownlint-disable-file MD024 -->

Все заметные изменения документируются в этом файле. Формат версий — [SemVer](https://semver.org/lang/ru/).

С июня 2026 фронт и бэк версионируются **раздельно** (одна общая нумерация продукта осталась в истории ниже):

- **Backend** — версия в `backend/pyproject.toml`. SemVer по контракту HTTP-API и машинным кодам ошибок (`code`). Теги `backend-vX.Y.Z`.
- **Frontend** — версия в `frontend/package.json`. Маркер релиза SPA (внешнего контракта нет). Теги `frontend-vX.Y.Z`.

CHANGELOG остаётся один. Новые записи группируются по дате, внутри — под-секции `### Backend X.Y.Z` / `### Frontend X.Y.Z` (а для repo-уровневых изменений — `### Project` без номера версии). Исторические записи ниже — общая продуктовая нумерация до разделения, помеченная областью (`· Backend` / `· Frontend` / `· Project`).

#### По итогам аудита редизайна

- **Perf: три.js убран с критического пути публичной зоны — 688 → 185 кБ gz (−73%).** `PublicLayout` тянул `PersistentGlobe` статически, поэтому текст hero не мог отрисоваться, пока не распарсится 1.8 МБ движка; доставалось и формам `/login`, `/signup`, где глобус — чистый фон. Теперь ленив сам холст, а не весь компонент: тёмная подложка и кадрирование по `data-screen` — это CSS, они появляются в первом кадре. Плюс рендер WebGL встаёт на паузу, когда вкладка скрыта
- **Контраст доведён до AA там, где он проваливался.** Заголовок краш-экрана и модалки верификации были практически невидимы (1.29:1 — остаток `slate.8` от светлой темы); метка на акцентной кнопке набиралась белым (2.40:1). Цвет метки теперь выбирает `autoContrast` в теме — это сняло семь ручных решений и `!important`-обход, из-за которого auth-кнопка отличалась от кнопок journeys
- **Один язык ошибок.** Auth-экраны красили сообщение своим `#ff9a8b` и своим кеглем, остальной продукт — мантиновским `c="red"`: одна роль звучала двумя цветами. Введён токен `--text-error`. Светлый оттенок отвергнут после примерки: он отличался от акцента всего на 16° тона и был светлее него, поэтому читался не как другой сигнал, а как выцветшая терракота
- **Шкала кеглей: 28 значений сведены к 11 ступеням.** Разброс был не смысловым, а пофайловым — роль «моно-штемпель» набиралась пятью кеглями, основной текст семью в диапазоне четырёх пикселей. Ступени поставлены на фактические моды распределения, поэтому 28 объявлений из 49 не сдвинулись вовсе, а среднее движение — 0.19px. Туда же сведены цвета (45 сырых `rgba` → канальные токены), длительности микро-анимаций (три → одна) и градиент «ночь» (три побуквенные копии → один токен)
- **Роутинг: неизвестный путь больше не даёт пустой экран** (`nginx` отдаёт `index.html` на любой URL, а ни одна ветка не совпадала), и залогиненный пользователь не видит форму входа в уже открытую сессию на `/login` и `/signup` — защита публичной зоны стала симметричной
- **A11y.** Ошибки форм получили `role="alert"` — до этого провал входа был виден только зрячему; в публичной зоне появился ландмарк `<main>`; заголовок вкладки меняется по разделу (был один на все девять маршрутов); шапка публичной зоны получила адаптив (на 320px она требовала больше ширины, чем есть, и давала горизонтальную прокрутку) и тап-таргеты 44px на сенсорных устройствах
- **i18n.** Дашборд перестал быть единственной страницей мимо переводов. Русский копирайт лендинга больше не обращается к читателю в мужском роде — правки сделаны сменой времени и конструкций, без переписывания смысла. Добавлены три формы множественного числа для русского
- **Безопасность и кэш.** Добавлена CSP (директивы выведены из собранного бандла, а не по шаблону: `blob:` не понадобился, `style-src 'unsafe-inline'` неизбежен из-за рантайм-инжекта переменных Mantine); самохостные шрифты получили годовой `Cache-Control` — без `immutable`, потому что Vite не хэширует их имена и обновление шрифта иначе не дошло бы до части пользователей
- **Тулинг и тесты.** Включён `strict` в TypeScript (дал ноль ошибок — код был написан strict-совместимо), локальный тулчейн выровнен с CI. Покрытие 86/80/87/87 → **97/91/96/98**, порог 90% взят по всем метрикам. Каталог `e2e/` впервые попал под тайпчек: он не входил ни в один tsconfig, из-за чего сломанные редизайном селекторы дожили молча. Компонентные тесты переведены на тёмную схему — раньше они проверяли продукт в противоположной, и потому не видели ни одной из контрастных регрессий выше

### Project

- **Реальный IP клиента за Caddy.** Прод-`uvicorn` получает `--forwarded-allow-ips` docker-подсети → `request.client.host` = настоящий IP клиента (аудит refresh-токенов, будущий rate-limit по IP), а не внутренний адрес прокси. Не `*` — иначе клиент подделал бы IP через `X-Forwarded-For`
- **Security-заголовки и non-root фронт-образ.** Caddy отдаёт `X-Content-Type-Options`/`X-Frame-Options`/`Referrer-Policy` на все ответы (и прячет `Server`); nginx фронта → `nginx-unprivileged` (non-root uid 101, `:8080`) + `server_tokens off`. HSTS не включаем (деплой по IP + self-signed)
- **Supply-chain hardening.** Базовые Docker-образы (node/nginx/python/uv в Dockerfile'ах; caddy/postgres/loki/promtail/grafana/postgres-backup в прод-compose) запинены по digest; Dependabot `docker` + `npm` держат digest'ы и фронт-зависимости свежими; `npm audit --audit-level=high` включён в frontend-гейт (симметрия с backend `uv audit`)
- **CI least-privilege и hygiene.** Deploy-job (только SSH) получил `permissions: {}` вместо унаследованного `contents: read`; `.dockerignore` фронта зеркалит backend — секреты (`.env*`) и тест-артефакты не попадают в build-контекст образа
